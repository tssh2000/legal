1. Overview

This privacy policy covers this website and the private software tool "NestCents Content Scheduler". The tool is used exclusively by the controller to schedule content on the controller's own Pinterest accounts and to retrieve analytics for the controller's own content. It has no other users; no personal data of third parties is processed.

2. Website hosting (GitHub Pages)

This site is served via GitHub Pages (GitHub Inc., USA). When you visit, GitHub processes technically necessary connection data in server logs (including IP address, date and time of the request, requested page, referrer, and browser/OS information). The legal basis is Art. 6(1)(f) GDPR (legitimate interest in secure, low-maintenance hosting). Transfers to the USA are safeguarded by the EU Standard Contractual Clauses (SCCs) implemented in GitHub's Data Protection Addendum. Log data is deleted once the purpose of processing no longer applies. See the GitHub Privacy Statement for details. This site itself sets no cookies and uses no analytics or tracking services.

3. Use of the Pinterest API by the tool

The tool accesses the controller's own Pinterest accounts via the official Pinterest API (Pinterest Europe Ltd., Ireland). It processes:

  • Access tokens (OAuth): for authentication with Pinterest; stored exclusively on a local device of the controller.
  • The controller's own content and analytics data: pins and boards created by the controller and their metrics (e.g. impressions, saves); stored exclusively locally until deleted by the controller.

The purpose is scheduling the controller's own content and evaluating its reach (Art. 6(1)(f) GDPR). No data of other Pinterest users is retrieved or stored, and no data is shared with third parties. Processing by Pinterest itself is governed by the Pinterest Privacy Policy.

4. Contact
